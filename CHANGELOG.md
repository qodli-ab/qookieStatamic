## 1.0.0 - 2026-09-05

### Added

- Initial Statamic addon for QookieQloud Consent Management.
- Automatic consent manager injection on public Statamic pages.
- Manual `{{ qookieqloud }}` Antlers tag for custom implementations.
- Statamic Control Panel dashboard for QookieQloud.
- Domain verification from the Statamic Control Panel.
- Dashboard metrics for consents, cookie scans and domain status.
- Settings for enabling the loader and deciding whether it should load for authenticated visitors.
- Dark-mode friendly Control Panel styling.
- QookieQloud icon support in the dashboard and Statamic navigation.
